# stepanix.com

The Stepanix home page: Klavko, Tapko and Duesko. English at the root, Ukrainian in `uk/`.

Everything is generated by `scripts/build.py`: edit the texts there, run `python3 scripts/build.py`, commit and push.
GitHub Pages serves this repository from `main` at stepanix.com.

To add an app, see the note at the top of `scripts/build.py`.
